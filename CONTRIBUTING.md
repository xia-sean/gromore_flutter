## What We Welcome / 欢迎的贡献

## Contribution Workflow / 提交流程

1. Fork the repository.
2. Create a branch in your fork.
3. Make a focused change.
4. Add or update tests when practical.
5. Document behavior changes in the README or CHANGELOG when needed.
6. Open a pull request back to `xia-sean/gromore_flutter`.

1. Fork 本仓库。
2. 在你的 fork 中创建分支。
3. 保持改动聚焦、单一。
4. 条件允许时补充或更新测试。
5. 如有行为变化，请同步更新 README 或 CHANGELOG。
6. 向 `xia-sean/gromore_flutter` 发起 Pull Request。

## Pull Request Notes / PR 说明

Please describe:

- What problem you fixed
- Why the change is needed
- How you verified it
- Whether the change affects Android, iOS, Flutter API, or examples

请在 PR 中说明：

- 修复了什么问题
- 为什么需要这次修改
- 你是如何验证的
- 是否影响 Android、iOS、Flutter API 或 example
